## The Error We Hit
Running: python run_selfplay.py val_test (in chess_onnx env)
Output:
  [onnx] exporting .../val_test_model.pt -> .../val_test_model.onnx
  AttributeError: 'collections.OrderedDict' object has no attribute 'parameters'
  in export_pt_to_onnx -> device = next(model.parameters()).device

## Root Cause
load_pt_model() in train_pytorch.py has this logic:
  obj = torch.load(path)
  if isinstance(obj, torch.nn.Module): return obj          # full model saved
  if isinstance(obj, dict) and "model" in obj: return obj["model"]  # checkpoint dict

The val_test_model.pt is a checkpoint dict: {"model": OrderedDict(...)}
where obj["model"] is a STATE DICT (OrderedDict of param tensors), NOT an nn.Module.
So load_pt_model returns the OrderedDict, then export_pt_to_onnx tries .parameters() on it -> crash.
